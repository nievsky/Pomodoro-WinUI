01_Exercise_StartButton

Exercise goal: XAML layout & click events

What the student must do:
- Open the `MainWindow.xaml` in this project and recreate a missing Start button (it's intentionally removed).
- Wire the button `Click` to the existing `PrimaryAction_Click` method in the code-behind.

Teacher setup:
1. Copy the project files from `00_Reference_CompletedApp` into this folder.
2. Remove the Start button XAML element from the timer area so students must add it back.
