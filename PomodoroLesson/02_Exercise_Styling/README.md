02_Exercise_Styling

Exercise goal: XAML properties & styling

What the student must do:
- Fix ugly UI colors and styles. The project's XAML has incorrect `Background` and `Foreground` values.
- Students should update resource brushes or explicit control properties to make the UI readable and visually pleasant.

Teacher setup:
1. Copy the project files from `00_Reference_CompletedApp` into this folder.
2. Change `App.xaml` resource brushes to intentionally bad colors (e.g., bright magenta backgrounds, unreadable text colors).
