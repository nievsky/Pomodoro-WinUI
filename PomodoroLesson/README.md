Pomodoro Lesson

This folder contains scaffolded lesson projects and exercise stubs for teaching WinUI 3 (XAML + C#).

Structure:
- 00_Reference_CompletedApp — instructions to provide the full working project to students.
- 01_Exercise_StartButton — exercise: recreate a missing Start button in XAML and wire it to `PrimaryAction_Click`.
- 02_Exercise_Styling — exercise: fix colors & styles in XAML.
- 03_Exercise_ClearHistory — exercise: add `Clear History` button in XAML and implement `ClearHistory_Click` to call `SessionHistoryList.Clear()`.
- 04_Exercise_BreakToggle — exercise: add `Checked` logic for two RadioButtons to set the timer display between "25:00" and "05:00".

See each exercise README for exact student instructions and files to edit.
